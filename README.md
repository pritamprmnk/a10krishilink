🌾 Project Name : KrishiLink – Social Agro Networking Platform

📍Project Overview:
KrishiLink is a modern social agro networking platform where farmers, traders, and consumers can connect, share crop posts, and collaborate directly without a traditional e-commerce system. The platform enables posting, browsing, and managing agricultural items with advanced search, detailed crop information, and interest-based interaction features.  


🌐 Live Link : https://krishilink10.netlify.app/

🧩 Features
Public Features
- Secure user registration & login (email/password & Google login)  
- Browse agricultural items with advanced search & detailed crop information  
- View and submit interests on crops  

User Dashboard
- Post, manage, and update crop items  
- Accept/reject buyer interests with real-time updates  
- Profile management and secure private routes  

Additional Features
- Fully protected private routes  
- Responsive and modern UI across **mobile, tablet, and desktop**  
- Dynamic sections and seamless navigation for user-friendly experience  

Technologies Used
- Frontend: React.js, HTML5, CSS3, Tailwind CSS  
- Backend: Node.js, Express.js  
- Database: MongoDB, Firebase (if used)  
- Other Tools: JWT Authentication, Google OAuth
